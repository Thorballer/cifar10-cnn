# CIFAR-10 CNN

A TensorFlow CNN for ten-class image classification with convolution, pooling, and batch normalization.

## Notebooks

- [notebooke3a86b3c6c.ipynb](notebooks/notebooke3a86b3c6c.ipynb) — [original Kaggle notebook](https://www.kaggle.com/code/thorballer/notebooke3a86b3c6c)

An early classification experiment using the original Kaggle dataset layout.

## Running

Open the original Kaggle notebook, attach its referenced data/models, choose the hardware expected by its setup cells, and run cells in order. Review install, login, and file-writing cells first.

For local use, install `requirements.txt` and adapt `/kaggle/input` paths. Dependencies are inferred from imports, not a tested lockfile; older APIs may need adjustment.

### Referenced Kaggle datasets

- [ayush1220/cifar10](https://www.kaggle.com/datasets/ayush1220/cifar10)
